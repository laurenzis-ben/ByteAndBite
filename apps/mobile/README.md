# ByteAndBite – Mobile (React Native + Expo)

Platzhalter. Hier entsteht die Expo-App. Zum Initialisieren in diesem Ordner:

```bash
cd apps/mobile
npx create-expo-app@latest .
npx expo start
```

API-Typen werden später aus dem OpenAPI-Schema des Backends nach
`packages/shared-types/` generiert und hier importiert – so bleiben Frontend
und Backend automatisch synchron.
